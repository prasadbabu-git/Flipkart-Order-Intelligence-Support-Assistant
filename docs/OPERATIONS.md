# Operations Guide

## Local development

1. Create a Python 3.11 virtual environment.
2. Install `requirements.txt`.
3. Run Part 1 to regenerate the deterministic order dataset/model.
4. Run Part 2 once with internet access to download Fashion-MNIST and ResNet-18 weights. The feature cache is generated locally and ignored by Git.
5. Run the API and dashboard.

## Model artifacts

- `models/return_risk_model.pkl` is the final Part 1 pipeline.
- `models/product_classifier.pt` is generated by Part 2 and loaded by `core/vision_engine.py`.

## Production notes

The policy KB is synthetic coursework content. Replace it with approved policy content before any real deployment. Keep confidence thresholds configurable and log retrieval/tool decisions for auditability.
