# 🛍️ Flipkart Order Intelligence & Support Assistant

An end-to-end AI/ML portfolio project that combines **return-risk machine learning, transfer-learning computer vision, policy RAG, LangGraph-style orchestration, FastAPI, and Streamlit** into one support platform.

> **Assignment alignment:** The implementation preserves the three-part PDF requirements: Part 1 return-risk scoring, Part 2 Fashion-MNIST transfer learning, and Part 3 RAG + LangGraph support agent. The additional API, dashboard, order intelligence, observability-oriented structure, tests, and Docker setup are portfolio-grade extensions.

## Architecture

```text
Streamlit Dashboard → FastAPI → Support Agent / LangGraph
                                   ├── Order Lookup + Return Risk
                                   ├── Policy RAG / FAISS
                                   └── Product Image Classifier

Part 1: orders_dataset.csv → preprocessing → Logistic/RF → return_risk_model.pkl
Part 2: Fashion-MNIST → ResNet-18 transfer learning → product_classifier.pt
Part 3: policies → embeddings/vector store → intent routing → tools → grounded response
```

## Project layout

- `part1/` — dataset/model training and evaluation
- `part2/` — Fashion-MNIST + ResNet-18 transfer learning and inference
- `part3/` — RAG, LangGraph workflow, tools, guardrails, transcripts
- `core/` — reusable order and vision engines
- `api/` — FastAPI service
- `app/` — Streamlit dashboard
- `models/` — final trained model artifacts
- `data/sample_images/` — real Fashion-MNIST test PNGs generated by Part 2
- `results/` — metrics, thresholds and evaluations

## Requirements

Python 3.11 is recommended. Part 2 requires internet access the first time it downloads Fashion-MNIST and the pretrained ResNet-18 weights. TorchVision's official documentation confirms Fashion-MNIST has 60,000 training and 10,000 test images and supports `download=True`. The ResNet preprocessing uses 3-channel images, at least 224×224, with ImageNet normalization.

## Quick start — Windows / VS Code

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Part 1

```powershell
python generate_orders.py
python part1/train_and_evaluate.py
```

Expected final artifact:

```text
models/return_risk_model.pkl
```

### Part 2

```powershell
python part2/train_classifier.py
```

This downloads Fashion-MNIST, creates a stratified validation split, extracts frozen ResNet-18 features, caches those features locally, trains the classifier head, optionally fine-tunes late layers when needed, evaluates the untouched test set, writes a 10×10 confusion matrix, exports five real test PNGs, and saves:

```text
models/product_classifier.pt
data/sample_images/*.png
results/part2_results.json
```

The feature cache is intentionally ignored by Git because it is a regenerable intermediate artifact and can exceed GitHub's normal file-size limit.

### RAG / agent tests

```powershell
python part3/retrieval_eval.py
python part3/test_suite.py
python part3/run_demo.py
```

### API

uvicorn api.main:app --reload
```

Open `http://127.0.0.1:8000/docs`.

### Dashboard

streamlit run app/dashboard.py
```

Open `http://localhost:8501`.

## GitHub large files

Do not commit `data/feature_cache/`. It is generated by Part 2. The final `product_classifier.pt` should be committed if it is under GitHub's regular per-file limit; otherwise use Git LFS. GitHub documents Git LFS as the mechanism for files beyond the normal repository file-size limit.

## Academic acceptance checklist

### Part 1
- Exact seeded 6,000-row generator
- Leakage-free preprocessing
- Dummy baseline
- Logistic Regression + threshold tuning
- Random Forest + 5-fold GridSearchCV
- ROC-AUC / F1 / precision / recall
- `t*_rf`
- feature and permutation importance
- subgroup analysis
- `models/return_risk_model.pkl`

### Part 2
- Fashion-MNIST 60k/10k
- stratified validation ≥5k
- untouched test set
- grayscale → 3-channel
- resize + ImageNet normalization
- pretrained ResNet-18
- frozen feature caching
- conditional fine-tuning
- confusion matrix + per-class metrics
- `models/product_classifier.pt`
- ≥5 real test PNGs

### Part 3
- ≥12 policy documents
- sentence-level chunks
- parent-document mapping
- embeddings + local vector store
- return-risk tool
- image-classification tool
- conditional LangGraph routing
- conversation state
- MOCK_LLM
- prompt-injection guardrail
- groundedness threshold
- ≥8 transcripts
- Precision@3 / Recall@3
